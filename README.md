## 🎭 Portfolio - Markus Christensen

Detta är en hemsida för en kompetent artist inom sång, musik och teater.

#### Syfte

Individuellt projekt i kursen JavaScript fördjupning i Frontend-utveckling på Medieinstitutet.

Detta ska fungera som en digital portfolio för Markus för att visa upp sina sceniska erfarenheter.

#### Funktioner

- Layout med Tailwind Css
- Hamburgermeny för mobil
- Bildgalleri med klickbara bilder och kort beskrivning
- Routing mellan sidor
- Responsivt

#### Installation

- `npm install`
- `npm run dev`

#### Tekniker

- React
- TypeScript
- Vite

#### Krav för Godkänt

1. ✔️ Minst 6 st komponenter varav minst 2 st är statefulla-komponenter
2. ✔️ React Router har använts för att dynamiskt uppdatera URL’en.
3. ✔️ Git & GitHub har använts
4. ✔️ Projektmappen innehåller en Readme-fil
5. ✔️ Uppgiften lämnas in i tid
6. ✔️ Muntlig presentation är genomförd
